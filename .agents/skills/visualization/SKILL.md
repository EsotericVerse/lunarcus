# visualization

LAS 視覺化主要對象是 Extension Queue、MCP Provider 的登入／授權狀態、Tunnel 資料映射進度、Auth/Cloudflare 部署、IPA／APK 打包狀態；資料必須有真實來源，錯誤狀態不可假裝已正常。

LOC TimeRiver/Trace、LRS 符文 VFX 不屬 LAS 的渲染核心。需要製圖套件或特定圖表 API 時才按需查來源，不為演示額外帶入 Recharts、MapLibre、Three.js 或符文特效。
