# ui-ux-pro-max

LAS 的 Chrome Extension 六頁由 `plugins/chrome/options-pages.js`、`options.html`、`options.css` 管理；確認總覽、每日符文、MCP 連線、擷取、Queue、設定都能導航，且既有右鍵選單、觸控目標、表單、鍵盤與焦點狀態可用。

必須檢查真實 Chrome UI／狀態，兼顧適當尺寸與對比、空資料／失敗訊息、焦點與 aria，不能只看 Build 或 SVG 截圖。材質與品牌質感才選 `impeccable`，避免雙主技能同時預載。
