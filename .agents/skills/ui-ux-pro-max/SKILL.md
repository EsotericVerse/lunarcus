# ui-ux-pro-max — LunArcus / LAS

LAS 的操作介面以 `plugins/chrome/{options.html,options.js,options-pages.js,options.css}` 為實際基準。六頁選單：總覽、每日符文、MCP 連線、擷取、Queue、設定；右鍵錄製、錯誤與手動發送不能因改版消失。

- 評估登入回饋、待送 Queue、Provider 連線、按鍵狀態、可讀性、手機窄版、鍵盤焦點、錯誤訊息與引導的準確性。
- 不把調整 LAS 畫面擴大成 LOC 網站首頁或 LRS 遊戲 UI 改版。
- UI 自動測試無法替代 Chrome 實際載入、OAuth callback 與寫入回執的行為確認。
- 品牌材質、動畫層次精修才改用 `impeccable`。
