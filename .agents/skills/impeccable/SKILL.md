# impeccable

使用 `plugins/chrome/options.html`、`options.css` 和實際渲染，精修 LunArcus／虹月的色彩、文字層次、亮暗材質、排版、圖示與互動回饋。不要照抄 LOC 主站的主題或 LRS 符文特效，也不要修改 Auth/Queue 標識來達成視覺更新。

一般響應式與動線問題由 `ui-ux-pro-max` 主導，視覺精修才用本 Skill，避免兩套審稿流程同時自動載入。必要時參照 Impeccable 官方可核對版本，僅取對應教學，不自動安裝二進位、Hooks 或大量動畫依賴。
