# impeccable — LunArcus / LAS

處理 LunArcus Chrome Extension 與未來 Plugins 的介面質感；先檢查 `plugins/chrome/options.html`、`options.css` 與原有圖像，不能套用 LOC 深藍主題假裝同款產品。

- 優先處理視覺層次、可讀性、色彩語意、模糊與陰影的效能，不能以漂亮動畫掩蓋登入或擷取錯誤。
- 不動 LRS 原創符文美術或 LOC Hero；LAS 負責自己品牌素材和交互呈現。
- 動態必須尊重 reduced-motion、鍵盤操作、窄螢幕、安全區與負載。
- 大幅設計前先做現有畫面對照。版面/導覽問題由 `ui-ux-pro-max` 主導，精修才選此 Skill。
- 參考 Impeccable 官方指引：https://github.com/pbakaus/impeccable
